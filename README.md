## 📱 ONE-CLICK INSTALLATION (LIKE APK)

### For Windows Users:
1. **Download** the latest `SupermarketERP_Setup.exe` from [Releases](https://github.com/ksdinesh-07/supermarket-erp/releases)
2. **Double-click** the downloaded file
3. **Click** "Next" → "Next" → "Install"
4. **Done!** The app starts automatically!
